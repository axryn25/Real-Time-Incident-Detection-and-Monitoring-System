DBMS Project Note • Grouping & Changefeeds

Data Consistency: High-frequency failure events arriving at POST /api/events for the same service and type within 5 minutes are grouped atomically into a single RethinkDB document using an atomic update with an in-process lock.

Real-Time Synchronization: The browser maintains a Server-Sent Events (SSE) connection to GET /api/incidents/stream. Express listens to RethinkDB's native r.table('incidents').changes() changefeed and pushes mutations instantly to this frontend without manual polling.
